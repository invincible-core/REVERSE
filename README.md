<h3><b>CHALLENGE</b></h3>

Every file here is obfuscated and encrypted, hiding a secret key inside.

1. Pick a file and a difficulty: Easy, Average, or Hard.
2. Deobfuscate it down to readable source.
3. Find the hidden key.
4. Send it to me on [Discord](https://discord.gg/invincible_core/).
